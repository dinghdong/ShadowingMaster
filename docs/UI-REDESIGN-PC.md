# ShadowingMaster · PC 端界面重设计方案

> 状态：方案评审稿（未开始实现）
> 目标：把当前「左侧固定导航 + 右侧内容网格」的 B 端感布局，改造成符合 toC 内容应用习惯的顶部导航 + 内容聚焦布局。

---

## 一、问题诊断

当前 PC 端（截图）采用左侧 252px 固定侧边栏承载全部导航：

- **信息层级被挤压**：侧边栏 + 顶栏双重占用水平空间，真正的视频内容区被压成窄列。
- **B 端既视感重**：左侧 Icon + 文字导航是后台管理系统常见模式，学习内容应用极少采用。
- **用户操作路径长**：「添加视频」作为最高频动作之一，被折叠在侧边栏底部；退出登录与学习入口并列，认知混乱。
- **内容 discoverability 差**：没有搜索、分类、进度筛选，用户只能按添加顺序扫完全部卡片。
- **视觉节奏平**：卡片大小、间距、进度提示都偏保守，缺少 toC 产品应有的呼吸感和成就感。

---

## 二、设计目标

1. **内容优先**：把视频网格和当前学习进度作为页面绝对主角。
2. **导航轻量**：用顶部 Tab / 搜索 / 用户菜单替代左侧边栏。
3. **情感化**：暖橙品牌色贯穿，加入「继续学习」「今日打卡」「学习 streak」等正向反馈。
4. **效率提升**：全局搜索 + 分类筛选 + 最近学习浮层，3 秒内进入目标视频。
5. **可落地**：完全复用现有 `tokens.css` / `components.css` 令牌与组件类，不引入新依赖。

## 三、信息架构调整

### 3.1 导航结构（PC）

```
顶部全局导航
├── 左侧：Logo + 主导航 Tab（视频列表 / 生词本 / 个人中心）
├── 中部：全局搜索框
└── 右侧：主题切换 + 添加视频按钮 + 用户头像下拉菜单
    └── 下拉菜单：个人中心 / 深色模式 / 退出登录
```

- **去掉侧边栏**：`DesktopShell` 的 `<aside class="sidebar">` 完全移除，主内容横向宽度释放。
- **Tab 导航**：当前页高亮， hover 时文字变主色，符合浏览器/内容平台心智。
- **添加视频**：提升到右上角主按钮（`btn--primary`），始终可见。
- **退出登录**：收进用户头像下拉，避免与功能导航平级。

## 四、视觉风格与令牌

严格沿用现有设计令牌，不新增色值：

| 元素 | 变量 | 说明 |
|------|------|------|
| 页面底色 | `--bg: #FFF8F0` | 暖米，保持整体温暖陪伴感 |
| 卡片 | `--surface: #FFFFFF` | 白卡，与底色形成清晰层级 |
| 品牌主色 | `--primary: #FF7F50` | 珊瑚橙，用于 Logo、按钮、进度、高亮 |
| 主按钮 | `.btn--primary` | 右上角「添加视频」 |
| 卡片阴影 | `--shadow-sm / --shadow-md` | 默认 sm，hover 升至 md |
| 圆角 | `--r-lg: 16px` | 卡片、欢迎区；搜索框 `--r-pill` |
| 间距 | `--sp-4 ~ --sp-8` | 8pt 网格，增大页面呼吸感 |

新增**仅布局类**，不新增视觉样式：

```css
/* 顶部导航 */
.topnav { position: sticky; top: 0; z-index: var(--z-sticky); }
.topnav__inner { max-width: 1320px; margin: 0 auto; }

/* 内容区 */
.page-wrap { max-width: 1320px; margin: 0 auto; padding: var(--sp-6) var(--sp-6) var(--sp-8); }

/* 欢迎区两栏 */
.hero { display: grid; grid-template-columns: 1fr 320px; gap: var(--sp-6); }

/* 视频网格 */
.video-grid { display: grid; grid-template-columns: repeat(auto-fill, minmax(280px, 1fr)); gap: var(--sp-6); }
```

## 五、关键组件设计

### 5.1 顶部导航（TopNav）

- 高度 72px，白色底（`--surface`），底部 1px `--border` 分隔。
- Logo：珊瑚橙文字 + 小橙子图形（可用现有 `Icon` 组件或 CSS 圆点）。
- 主导航 Tab：文字按钮，激活态底部 2px 主色下划线。
- 搜索框：圆角药丸，占位文案「搜索视频标题…」，聚焦时主色光环。
- 右侧：主题切换 `icon-btn`、主按钮「+ 添加视频」、用户头像下拉。

```tsx
// 伪代码
<TopNav>
  <Logo />
  <NavTab active="list">视频列表</NavTab>
  <NavTab>生词本</NavTab>
  <NavTab>个人中心</NavTab>
  <SearchInput placeholder="搜索视频标题…" />
  <ThemeToggle />
  <Button primary>+ 添加视频</Button>
  <UserMenu user={user} onLogout={…} />
</TopNav>
```

### 5.2 欢迎区（Hero）

左侧：
- 问候语：`早安，aaa 👋`（按时间变化：早上/下午/晚上）
- 主文案：「今天继续攻克 MrBeast 吧」或「今天想学点什么？」
- 继续学习按钮：`btn--primary`「继续学习」

右侧（学习统计卡）：
- 已学句子数、已学视频数、连续学习天数（streak）
- 用 `.stat-card` 横向排列三个小卡

### 5.3 继续学习卡片

若用户有学习进度，在网格上方展示一张横向大卡：
- 左侧视频封面（小尺寸 160×90）
- 标题 + 进度条 + `上次学到第 X 句`
- 右侧「继续学习」主按钮

这是 toC 产品常见的「Continue Watching」模式，能显著降低再次进入成本。

### 5.4 视频卡片增强

基于现有 `.video-card` 调整：
- 封面比例 16:9，圆角 `--r-lg`。
- hover 时阴影升一级 + 微微上浮（已有 `.video-card:hover`）。
- 新增进度条覆盖在封面底部：
  - 已完成句数 / 总句数，用 `.bar` + `.bar__fill` 展示。
  - 进度条高度 4px，主色填充。
- 标题最多 2 行，与现有一致。
- 元信息一行：时长 · 句数 · 上次学到第 N 句（主色强调）。

### 5.5 筛选与排序

- 左侧 Chip 组：全部 / 在学中 / 已完成 / 最近添加
- 右侧下拉：排序（最近学习 / 最新添加 / 时长从短到长）
- 使用现有 `.chip` 和 `.segmented` 组件。

## 六、交互动效

全部使用现有 CSS 变量，不新增关键帧：

| 场景 | 动效 | 变量 |
|------|------|------|
| 页面入场 | 内容区 `.fade-up` | `--dur-normal` |
| 卡片 hover | 上移 2px + 阴影升级 | `--dur-normal` |
| 按钮 hover | 背景加深 + 微浮 | `--dur-fast` |
| Tab 切换 | 下划线过渡 | `transition` |
| 搜索聚焦 | 主色光环 3px | `--dur-fast` |
| 主题切换 | 背景色/文字色渐变 | `--dur-normal` |

## 七、响应式策略

- **PC（≥900px）**：本方案生效，顶部导航 + 欢迎区 + 4 列网格。
- **平板（640px–899px）**：网格变为 2–3 列；欢迎区堆叠为单列。
- **手机（<640px）**：维持现有移动端结构（顶部精简导航 + 单列卡片），不引入本方案的欢迎区，避免信息过载。

## 八、全部页面统一设计

顶部导航（TopNav）是全局壳，覆盖 `list / wordbook / profile / add / practice` 五个应用页；`landing / login` 为全屏独立页（见 §8.6）。

### 8.1 生词本页（/wordbook）

```
TopNav[active=生词本]   🔍 搜索生词    + 添加视频  👤
────────────────────────────────────────────────
我的生词本                          共 24 个
[全部] [最近添加] [按视频]           ↧ 排序
┌────┐ ┌────┐ ┌────┐ ┌────┐
│word│ │word│ │word│ │word│   ← WordBookCard 网格
└────┘ └────┘ └────┘ └────┘
```

- 页面标题区：`我的生词本` + 总数；右侧搜索框（按单词 / 释义 / 来源视频搜）。
- 筛选 Chip：`全部 / 最近添加 / 按视频`（按来源视频分组，组内按句子序）。
- 网格：复用现有 `.list-grid` + `WordBookCard`（词头 + 音标 + 释义 + 例句 + 来源）；hover 轻浮，点击弹 `WordPopup`。
- 空态：插画 + 「还没有收藏生词，去跟读时点击高亮词加入吧」+ 主按钮「去跟读」。
- 未登录：`LoginGate` 居中。

### 8.2 个人中心页（/profile）

```
TopNav[active=个人中心]   🔍   + 添加视频  👤
────────────────────────────────────────────────
[👤] aaa@mail.com              已加入 12 天
┌─────┐ ┌─────┐ ┌─────┐
│ 3   │ │128  │ │24   │   ← stat-card：学习视频/学习句数/生词
└─────┘ └─────┘ └─────┘
学习记录
┌────┐ ┌────┐ ┌────┐
│card│ │card│ │card│   ← VideoCard 网格（复用）
└────┘ └────┘ └────┘
[🌙 深色模式]   [退出登录]
```

- 顶部 Profile 头卡：头像 + 邮箱 + 已加入天数。
- 统计三卡：复用 `.stat-card`（学习视频 / 学习句数 / 生词）。
- 学习记录：`section-label` + `VideoCard` 网格（已复用）。
- 设置区：深色模式开关（复用 `.toggle`）+ `btn--danger` 退出登录按钮（原在侧边栏，现明确落在页面）。
- 未登录：`LoginGate` 居中。

### 8.3 添加视频页（/add）

```
TopNav[active=视频列表]   🔍   + 添加视频(高亮)  👤
────────────────────────────────────────────────
             ┌──────────────────────────┐
             │ 粘贴 YouTube 链接…        │
             │ [URL 输入] [解析]         │
             │ ████████░░ 解析中…        │
             └──────────────────────────┘
              支持 youtube.com/watch?v=…
```

- 顶部仍是常规 TopNav；「添加视频」按钮在列表中高亮或保持列表激活，点击进入此页。
- 页面内居中卡片（`max-width: 640`）：说明 + URL 输入框 + 解析按钮 + 进度条 + 状态 + 错误提示（复用现有结构）。
- 未登录：`LoginGate` 居中。
- 此页保持聚焦，不加额外装饰。

### 8.4 跟读页（/video/:id）

```
TopNav[logo / 视频列表 / 生词本 / 个人中心]   🔍  +  👤
────────────────────────────────────────────────
[←] I Meet MrBeast…        [英中▾]  [⚙]
┌─────────────────────┐   ┌─────────────────┐
│   ▶ 视频播放器 16:9   │   │ ① 英文句        │
│                       │   │ ② 英文句(当前)  │
├─────────────────────┤   │ ③ 英文句        │
│ [原文][跟读][听写][挖空]│   │ ④ 英文句        │
│ 当前句练习台          │   │ …              │
│ [🎤 跟读] 识别结果    │   └─────────────────┘
└─────────────────────┘
```

- **保留全局 TopNav**（logo/tabs/搜索/添加/用户），便于跨页跳转与打开生词本。
- TopNav 下方为页面子头（原 `player-bar` 角色）：返回箭头 + 视频标题 + 字幕切换 + 设置齿轮（设置弹层复用现有 `.popover`）。
- 主体布局沿用已落地的左右分栏（左：视频 + 模式分段 + 当前句练习台；右：全句滚动列表）。去掉侧边栏后左栏更宽，播放器可放大。
- 移动端：维持现有 `player-frame` sticky + 列表就地展开，不受 TopNav 影响（移动端 TopNav 已是精简版，见 §8.7）。

### 8.5 落地页 / 登录页（不参与侧边栏）

- **落地页（LandingPage）**：已有酷炫 hero（极光 / 声波 / CTA）。建议顶部加一个极简透明 TopBar：左 Logo，右「登录」按钮；向下滚动时底色渐变为白（保持品牌一致）。不引入新设计语言，仅补导航。
- **登录页（LoginPage）**：聚焦认证卡，不加应用 TopNav；保留「返回首页」文字链。

### 8.6 移动端（<900px）一致性

- 移动端本来就没有侧边栏（`.sidebar{display:none}`），各页用独立 `.navbar`（返回 + 标题）。
- 改造后：移动端统一用 TopNav 的紧凑版（Logo + 当前页标题 + 右侧图标），去掉各页独立的返回按钮，改用顶栏 Logo 回首页或保留轻量返回。
- 跟读页视频 sticky 逻辑保持不变。

- 不修改跟读页 `PracticePage` 的左右分栏练习结构（仅在其外包裹一层全局 TopNav，并把原 player-bar 作为页面子头）。

### 9.3 数据需求

当前 `AppState` 已提供的数据足够：
- `videos`：视频列表

## 十、A11y 与性能

- 顶部导航使用 `<nav>` + `<ul>/<li>`，当前页 `aria-current="page"`。
- 搜索框带 `role="search"` 和 `label`。
- 用户头像下拉使用按钮 + 键盘 Escape 关闭。
- 卡片 hover 效果配合 `prefers-reduced-motion` 自动禁用。
- 封面图保持 `object-fit: cover`，不强制预加载大图。

- [ ] 移动端（<900px）布局不被破坏。
